# Charged patchy particle models (CPPM) in crowded solution

Simulation inputs, raw results and analysis scripts for the CPPM osmotic-pressure study.
Thirty CPPM macroions (cubic box, 149.6 Å) at volume fraction φ ≈ 0.3 are simulated with explicit, grand-canonical
1:1 salt and, for comparison, with implicit ions (screened Coulomb, Debye length 1/κ).
Osmotic pressure is sampled with virtual volume moves.

The charge distributions follow the manuscript notation:

| Folder name   | Symbol | Charge pattern                     |
|---------------|--------|------------------------------------|
| `isotropic`   | P⁰₀    | uniform negative charge            |
| `dipolar`     | P¹₈    | one positive patch of 8 groups     |
| `quadrupolar` | P²₈    | two patches of 8 groups each       |
| `neutral`     | Pⁿ     | uncharged reference                |

## Setup

Requires [uv](https://docs.astral.sh/uv/). It installs Python 3.12 and the exact
package versions in `uv.lock`:

```sh
uv sync
```

## Layout

```
analysis/              Analysis and plotting scripts
  make_figures.sh      Regenerates every figure in figures/
  invariants.py        Kirkwood–Buff and orientational invariants, GP surrogate
simulation/            Faunus input template, input generator and sweep scripts
  structures/          Macroion structures (P00, P18, P28, Pneutral)
data/                  Simulation results used in the manuscript
  explicit/            Explicit-ion runs, 3 replicas per variant (+ bulk salt)
  implicit/<variant>/  Implicit-ion κ scans, 3 replicas per κ
  fluctuations/        Explicit-ion runs with per-step pressure and ion-count series
  geometry/            Isotropic implicit-ion runs with ion-excluded-sphere charge scaling
figures/               Generated figures (output of make_figures.sh)
  schematics/          Model schematics and VMD renders (not regenerated)
```

Implicit run folders are named `<variant>-imp_<κ>[_<replica>]`, with κ in Å⁻¹. Folders
ending in `_exp` use κ = 0.104 Å⁻¹, the Debye–Hückel value at the ionic strength of the
explicit-ion runs. Each run folder holds:

| File                  | Content                                                      |
|-----------------------|--------------------------------------------------------------|
| `input.yml`, `input_equi.yml` | Faunus input for production and equilibration        |
| `output.yaml`         | Averages, acceptance ratios, osmotic pressure, Faunus version |
| `rdf.csv`             | Macroion–macroion centre-of-mass g(r)                        |
| `multipole_dist.csv`  | Multipole energies and orientational correlations vs. R     |
| `energy.csv.gz`       | Energy time series                                           |
| `state.yaml`          | Final configuration (restart file); explicit runs also keep `confout.*` for VMD |

### Sampling, salt fluctuations and the geometry test (ESI)

`data/fluctuations/` holds explicit-ion runs at the production state point that record the
virtual-volume estimator (`vvm.csv.gz`) and the Na⁺ and Cl⁻ counts (`n_na.csv.gz`,
`n_cl.csv.gz`) at every step. `data/geometry/` holds isotropic implicit-ion runs at the
free-salt Debye lengths whose bead charges are scaled by A_ex/A_sh, the Debye–Hückel
amplitude of a sphere that excludes ions from radius a_ex (folder `geo<a_ex>`) over that of
a charged shell in electrolyte. These scripts print the ESI numbers:

```sh
uv run analysis/autocorr.py data/fluctuations             # correlation times, block errors
uv run analysis/salt_susceptibility.py data/fluctuations  # ⟨δN_s²⟩ and the Donnan ratio
uv run analysis/finite_size_kb.py data                    # KB cutoff, tail correction, weights
uv run analysis/geometry_test.py data                     # charge-scaled runs vs. explicit ions
```

### Choosing the implicit-ion Debye length

`plot_kappa_analysis.py --fit-mode` selects the best κ by one of:

- `peak`: matches the height of the first g(r) peak;
- `rmsd`: plain RMSD of g(r);
- `weighted`: shell-volume weighted RMSD, [∫(Δg)² r² dr]^½;
- `mayer`: |∫Δg r² dr|, the uncorrected Kirkwood–Buff difference;
- `kb`: zero of the signed, finite-size-corrected Kirkwood–Buff difference ΔG;
- `joint`: minimum of the matching score S from `kappa_invariants.py` (used by `make_figures.sh`).

`kappa_invariants.py` reports λ* = 1/κ* separately for each invariant (Kirkwood–Buff,
dipolar and quadrupolar orientational projections of g(r)), fitted with a Gaussian
process, together with a matching score S that also includes the g(r) residual.

## Running simulations

Simulations use [faunus-rs](https://github.com/mlund/faunus-rs), expected as a sibling
checkout built at `../faunus-rs/target/release/faunus`. `git_revision` in each
`output.yaml` records the build that produced a run.

```sh
# Dry run: writes inputs to data/runs/ (git-ignored) without running Faunus
simulation/run_sweep.sh --systems dipolar --kappas 0.08,0.09 --replicas 3
# Run locally
simulation/run_sweep.sh --systems dipolar --kappas 0.08,0.09 --replicas 3 --submit
# Submit to the LUNARC cluster (SLURM); same options
simulation/launch_sweep.sh --systems dipolar --kappas 0.08,0.09 --replicas 3
```

Omitting `--kappas` runs explicit-ion simulations.

The defaults (N = 30, φ = 0.3, 40 000 production and 20 000 equilibration steps) reproduce
the inputs in `data`, apart from the structure path. Exceptions: the explicit runs
equilibrate for 4 000 steps (`--equil-micro-steps 400`) and include `SpatialDistribution`
analyses, which the template lacks; the neutral explicit runs use 32 000 production and
12 000 equilibration steps.

## Known issues

- **SDF axes.** The explicit-run `.dx` grids (faunus-rs v3.0.0-beta.2-54) are stored
  x-fastest instead of z-fastest, so standard readers swap x and z; the `.dx` header does
  not record the order. Builds from v3.0.0-beta.2-55 on write z-fastest.
  - `plot_sdf_sphere.py --swap-xz auto` (the default) reads `git_revision` from the
    `output.yaml` next to each file and swaps only x-fastest grids;
  - the VMD renders use the `ref_*_swapxz.xyz` references instead.
- **Kirkwood–Buff convergence.** The boxes reach only L ≈ 1.87σ, where G(L) has not
  levelled off. `finite_size_kb.py` tests how ΔG and λ* depend on the cutoff and on a
  closed-system correction (`invariants/delta_G_vs_L`).
